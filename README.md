## 🚀 How to Run the API Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Start the FastAPI server: `uvicorn app:app --reload`
3. Access the interactive API docs at: `http://127.0.0.1:8000/docs`

*Note: The UI represented in the screenshots is a frontend design mockup. The current codebase serves the backend machine learning REST API.*
